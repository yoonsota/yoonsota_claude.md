# SuperPower-Up

I've been enjoying [Superpowers](https://github.com/obra/superpowers), but I started wanting a little more out of it.

There are so many great skills and tools out there. What if I could make them all work nicely with Superpowers?

So here I am, mixing things together, trying different combinations, and occasionally tearing things apart to start over.

The idea is to keep Superpowers at the core, add what's useful, and cut out unnecessary complexity and overlap.

**The goal? A pretty solid coding harness. Eventually.**

## Current Plan

```text
Research
   │  Explore options & technical constraints
   ▼
Requirements
   │  Define requirements & design decisions
   ▼
Development
   │  Superpowers
   │  ├─ Spike
   │  ├─ Bounded
   │  └─ Architectural
   ▼
Final Quality
   │  Simplify
   │  Independent Review
   │  Verify
   ▼
Done!
```

Each stage is explicitly started by the user. Superpowers handles the core development workflow, while other skills and tools provide support where needed.

**Supporting tools & skills**

- **Matt Pocock Skills** — Research, requirements, design, and review
- **Graphify** — Codebase exploration and impact analysis
- **Context7 / GitHub MCP** — Library documentation and upstream references
- **NVIDIA Skills** — NVIDIA-specific development support
- **Karpathy Guidelines / Code Simplifier** — Coding principles and cleanup

Not everything needs to run every time. The idea is to use the right tools when they're actually needed.
